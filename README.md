# SUIT Solar Workshops

Hands-on tutorials for SUIT data analysis using SunPy.

---

## Local Installation

Clone the repository:

```bash
git clone git@github.com:soumyaroy799/SUIT_solar_workshops.git
cd SUIT_solar_workshops
```

Create the environment:

```bash
conda env create -f environment.yml
conda activate workshopenv
```

Launch Jupyter:

```bash
jupyter lab
```
